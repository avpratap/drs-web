# drs-web

DRS web app — **Next.js (App Router) + Refine admin**, deployed on Vercel.
Uses the 5 DRS brand colours (see the `drs-brand` / `drs-frontend` skills in `drs-platform`).

## Scaffold (next step)
```bash
pnpm create next-app@latest . --ts --tailwind --app --eslint
```
Talks to the FastAPI backend via an OpenAPI-generated TypeScript client.
